# Native extension qualification

These results qualify the native import, mesh/scene, authoring and cache additions
on the pinned Anny assets. They do not replace the earlier Python-reference
record in `VALIDATION.md`, and are not a claim that every proposed extension is
complete. Native runtime and all operations below ran without Python subprocesses.

## Fast and target checks

- Rust 1.90.0: `cargo fmt --all -- --check`: passed.
- `cargo test --workspace --locked`: **36 passed**, three asset-dependent tests
  intentionally ignored in the fast run.
- `cargo clippy --workspace --all-targets --locked -- -D warnings`: passed.
- `cargo check -p anny-wasm --target wasm32-unknown-unknown --locked`: passed.
- `cargo build --workspace --release --locked`: passed.
- C ABI executable: full 13,718-vertex / 27,420-face body, measurement query,
  rigged GLB bytes, model transformation, pose transfer, prepared bytes and
  reload all passed. C and Rust ownership were exercised across actual calls.
- The C# executable now exercises the same secondary lifecycle, rather than only
  compiling P/Invoke declarations. Its execution is a separate CI check.

Fast tests cover malformed archive rejection, UV/index remapping, sparse glTF
accessors, PLY/STL/OBJ round trips, multi-object rigged scene and skeletal animation
structure, transform synchronization, signed interpolation, rig filtering,
secondary operation errors, native fitting modes, cache hit/invalidation and
corruption rejection. Native archive qualification also compares all eight
committed `.pth`/`.pt` archives against their converted Safetensors equivalents.

## Independent glTF checks

Khronos `gltf-validator` 2.0.0-dev.3.10 was run against actual generated bytes:

| Input | Errors | Warnings | Informational messages |
| --- | ---: | ---: | ---: |
| Full Anny character, 104 bones | 0 | 0 | 2 |
| Two-character synthetic scene with skeletal animation | 0 | 0 | 1 |

The extra source-vertex map in glTF `extras` allows our geometry importer to
recover correspondence after seam splitting. This is not a claim that arbitrary
third-party GLBs have Anny vertex correspondence. Only the supported uncompressed
triangle glTF subset is imported. Materials and animation clips are not retained
by the geometry-only importer.

## Real preprocessing qualification

Run these explicit tests when the committed asset payload is present:

```sh
cargo test -p anny-core --release --locked --test native_import -- --ignored --nocapture
cargo test -p anny-core --release --locked --test authoring -- --ignored --nocapture --test-threads=1
```

Both authoring tests passed against the original committed reference tensors.
Maximum absolute differences:

| Archive / tensor | Difference |
| --- | ---: |
| Anny template covariance | 4.0719239979836175e-8 |
| Anny morph covariance | 3.7339729974661395e-8 |
| Anny reference orientation | 1.723906197792502e-7 |
| SOMA template covariance | 6.774134204967641e-13 |
| SOMA morph covariance | 6.151885099427157e-13 |
| SOMA reference orientation | 0 |

Raw MakeHuman skin-weight cleanup matched every weighted reference entry within
**3.3306690738754696e-16**. Unweighted detached helper vertices still follow the
port's documented root-binding rule; this is not NaN/unused-vertex parity.
SOMA covariance generation uses the repository's authored SOMA rig/RBF data,
not an external Python SOMA-X package or either precomputed orientation archive.

## End-to-end operational checks

The native CLI successfully exercised a real-data cache miss and hit, prepared
model creation, transformed-model save/reload, measurements, rigged GLB generation,
mesh fitting in both correspondence modes, and asset verification (1,568 manifest
entries). One-iteration self-mesh round-trip probes produced:

- Index-correspondence mean vertex error: approximately `2.28835e-7` meters.
- Closest-surface forward distance: approximately `8.37975e-8` before and
  `7.03411e-8` after the accepted iteration.

These are round-trip smoke tests, **not scan registration/convergence benchmarks**.
The benchmark command's two-iteration operational smoke also passed; two samples
are insufficient for a throughput or real-time performance claim.

## Still outside this qualification

- Full 23-case Python forward reference suite was not regenerated for this
  extension; the previous result remains separately recorded.
- No actual browser execution, Unity runtime, GPU implementation or performance
  guarantee is asserted by a successful WASM compile.
- No general automatic differentiation / `post_gd` optimizer, native f32 evaluation
  backend, full AMASS/SMPL-X fitting workflow, or exhaustive collision/optimizer
  equivalence is asserted here.
- Geometry glTF export is not full morph-channel/PBR-material authoring parity.

Current capability boundaries are in `COMPATIBILITY.md` and `AUTHORING.md`.
